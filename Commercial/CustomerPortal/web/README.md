# THE GOLD MIND — Customer Portal (Web)

**Phase 9 · Sprint 2 MVP**  
Standalone commercial Next.js app. **No Core Trading Engine dependency.**

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000 — use **Demo Sign-In**, or configure Google OAuth in `.env.local`.
