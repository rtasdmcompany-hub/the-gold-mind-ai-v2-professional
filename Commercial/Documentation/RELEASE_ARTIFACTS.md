## C. Expected after a successful production build (Owner target set)

These are the artifacts a production release train should produce and store (recommended paths):

### Windows commercial

| File | Expected location |
|------|-------------------|
| `TheGoldMindSetup.exe` (or signed `Setup.exe`) | `Commercial/Releases/<version>/` and/or CDN |
| Optional MSI | `Commercial/Releases/<version>/` |
| `TGM_PROFESSIONAL_<version>_<channel>.zip` | `Commercial/Releases/<version>/` + portal artifact store |
| `TGM_PROFESSIONAL_<version>_<channel>.zip.sha256` | Same folder |
| Authenticode signature evidence | Sign log / catalog alongside Setup |
| `SBOM.json` (or CycloneDX) | `Commercial/Releases/<version>/` |

### MetaTrader

| File | Expected location |
|------|-------------------|
| `TheGoldMindAI_Professional.ex5` | Inside release ZIP under `MQL5/Experts/` (or documented MT5 deploy path) |
| `TheGoldMindAI_Professional.mq5` (if distributing source) | Optional; Market rules may differ |
| Required `Include/` subset | Packaged with EA per Market/Website rules |
| Core SHA attestation | `CORE_SHA256.txt` beside package |

### Portal

| File | Expected location |
|------|-------------------|
| Next.js production build | `.next/` after `npm run build` (deploy artifact) |
| Env template | `.env.local.example` (present) |

### Documentation pack

| File | Expected location |
|------|-------------------|
| Release notes | `Commercial/Releases/<version>/RELEASE_NOTES.md` (RC-2 sample exists) |
| Version metadata | `VERSION.json` (RC-2 sample exists) |
| Rollback archive | Previous ZIP retained under `Commercial/Releases/` or updater `rollback/` |

### Runtime-generated (when portal is running)

| File | Location |
|------|----------|
| Commercial-shell ZIP | `Commercial/CustomerPortal/web/.data/releases/artifacts/<packageId>.zip` |
| Note | Generated by code; **not** a substitute for committed signed Setup + EA package unless deliberately promoted |
