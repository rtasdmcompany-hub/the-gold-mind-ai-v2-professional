## Verdict

**PASS — central brand configuration is live.**

Customer-facing brand values resolve from:

1. **`Commercial/CustomerPortal/web/src/lib/brand.ts`** (canonical defaults + env overrides)
2. **Environment variables** (`NEXT_PUBLIC_BRAND_*`, `BRAND_*`, and domain-matched `RESEND_FROM_EMAIL`)

## How to change the brand once

### Option A — code defaults

Edit defaults in `src/lib/brand.ts`, then:

```bash
cd Commercial/CustomerPortal/web
npx tsx scripts/export-brand.mjs
```

### Option B — environment only (preferred for domain cutover)

Set on Vercel / `.env.production`:

```env
NEXT_PUBLIC_BRAND_DOMAIN=thegoldmind.ai
NEXT_PUBLIC_BRAND_WEBSITE=https://thegoldmind.ai
NEXT_PUBLIC_BRAND_SUPPORT_EMAIL=support@thegoldmind.ai
NEXT_PUBLIC_BRAND_BILLING_EMAIL=billing@thegoldmind.ai
NEXT_PUBLIC_BRAND_LICENSE_EMAIL=license@thegoldmind.ai
NEXT_PUBLIC_BRAND_ADMIN_EMAIL=admin@thegoldmind.ai
NEXT_PUBLIC_BRAND_NOREPLY_EMAIL=noreply@thegoldmind.ai
RESEND_FROM_EMAIL=THE GOLD MIND PROFESSIONAL <noreply@thegoldmind.ai>
```

Redeploy portal. Re-run export script before rebuilding the Windows installer.

## Safety rules

- `RESEND_FROM_EMAIL` values that do **not** use `brand.domain` are **ignored** (prevents shared-infra From addresses leaking into customer mail).
- Customer-facing support address comes from `BRAND_SUPPORT_EMAIL` / domain default — not from a foreign `SUPPORT_EMAIL`.
- `SUPPORT_INBOX_EMAIL` may still route intake to an operator mailbox without changing the published brand address.
- Infrastructure account names (Resend/Google/Paddle/Upstash, GitHub/Vercel org slugs) remain out of `brand` customer identity.
