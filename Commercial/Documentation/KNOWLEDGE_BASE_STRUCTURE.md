## 2. Article template

```
Title
Summary (2 sentences)
Applies to: Professional | Market | Both
Steps / Answer
Screenshots (optional)
Related articles
Still need help? → Create ticket (pre-filled category)
```

## 3. Search & findability

- Tags: edition · version · symptom codes (`LIC_*`, `UPD_*`)  
- “Was this helpful?” → feeds Feedback System  
- Pin Top 10 on Support Dashboard

## 4. Maintenance

| Event | KB action |
|-------|-----------|
| Public Stable release | Update Install/Activate/Update articles |
| Known issue | Troubleshooting + Announcement link |
| Retired feature | Mark deprecated; don’t delete abruptly |

## 5. Tone rules

Precise · calm · premium.  
No hype. No “guaranteed profits.”  
Core sole execution authority stated where customers might misunderstand AI.
