## 1. Purpose

Every customer must complete this loop without confusion:

**Purchase → Install → Activate → Learn → Trade → Update → Get Help → Renew**

Support quality must feel as premium as the software.

## 3. Area definitions

### Support Dashboard
- Open tickets · SLA clocks · recent announcements · system status chip  
- Quick actions: New ticket · Search KB · Download latest · Diagnostics pack help  

### Support Tickets
- Create / track / reply / attach diagnostics (customer-initiated)  
- Status: Open · Pending Customer · Pending Support · Escalated · Resolved · Closed  

### Ticket Categories
See `SUPPORT_OPERATIONS.md` (Bug · Feature · License · Payment · Technical · General · Account Recovery).

### Priority Levels
P1 Critical · P2 High · P3 Normal · P4 Low — matrix in Support Operations.

### Live Status
- Agent availability (business hours) · expected first response  

### Knowledge Base
- Full IA in `KNOWLEDGE_BASE_STRUCTURE.md`  

### Video Tutorials
- Install · Activate · First run · Dashboard tour · Reports · Updates  
- Short, silent-friendly captions; Premium Black/Gold end cards  

### FAQ
- Top 20 friction answers; link deeper KB articles  

### Release Notes
- Customer language; aligned with Sprint 7 versioning  

### Downloads
- Latest Professional package · checksum · prior N versions policy  

### Announcements
- Product · maintenance · security · commercial policy  

### System Status
- Public status: Operational · Degraded · Outage (license/portal/update feeds — not broker)

## 4. What Support Center never does

- Remote trade execution  
- Asking for broker passwords  
- Guaranteeing profits  
- Changing Core risk/strategy on behalf of “support magic”
