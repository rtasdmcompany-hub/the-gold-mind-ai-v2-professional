# CUSTOMER_SUCCESS_JOURNEY.md

**Phase 8 · Sprint 8**  
**Nature:** Friction review + **recommendations only**  
**Goal:** Visitor → Long-Term Customer without confusion

---

## 1. Journey map

```
Visitor → Purchase → Download → Installation → Activation
  → Welcome Wizard → First Successful Trade → Learning
  → Regular Use → Update → Renewal → Support → Long-Term Customer
```

---

## 2. Stage friction & recommendations

### Visitor
| Friction | Recommendation |
|----------|----------------|
| Unclear Professional vs Market | Edition comparison on website (Sprint 1) |
| Feature hype vs truth | Honest scope; Core freeze language |
| Weak brand first viewport | Brand-first hero (Sprint 4 rules) |

### Purchase
| Friction | Recommendation |
|----------|----------------|
| Checkout confusion | Paddle/PayPal abstraction clarity (Sprint 3) |
| Wrong edition bought | Confirm edition before pay |

### Download
| Friction | Recommendation |
|----------|----------------|
| Can’t find package | Portal Downloads + post-purchase email |
| Checksum ignored | Show verify steps in email + KB |

### Installation
| Friction | Recommendation |
|----------|----------------|
| MT5 path unknown | Installer + Quick Start screenshots |
| Attach to wrong chart | Wizard System Check |

### Activation
| Friction | Recommendation |
|----------|----------------|
| Key typo / seat full | Masked key · device management link |
| Offline | Grace messaging + reconnect CTA |

### Welcome Wizard
| Friction | Recommendation |
|----------|----------------|
| Too many clicks | 7-page cap (Sprint 2); skip advanced |
| Prefs feel like live risk write | Catalog-only; never write Core risk |

### First Successful Trade
| Friction | Recommendation |
|----------|----------------|
| Fear / no guidance | Demo recommended path; Trading Guide |
| Expect AI to “take over” | Explicit: Core executes; AI advises |
| Magic 0 confusion | Explain manual vs EA isolation |

### Learning
| Friction | Recommendation |
|----------|----------------|
| Docs scattered | Documentation Center + KB categories |
| No videos | Tutorial playlist in Support Center |

### Regular Use
| Friction | Recommendation |
|----------|----------------|
| Dashboard overload | 3-second scan widgets (Sprint 4/5) |
| “What is it doing?” | Journal Reason + Health |

### Update
| Friction | Recommendation |
|----------|----------------|
| Fear of break | Backup · notes · rollback (Sprint 7) |
| Market users confused | Separate Market update KB |

### Renewal
| Friction | Recommendation |
|----------|----------------|
| Surprise expiry | T-30…T-1 reminders · Portal Subscription |
| Payment fail | Grace + clear banner |

### Support
| Friction | Recommendation |
|----------|----------------|
| Ticket black hole | SLA · status · confirmation email |
| Repeating basics | KB deflect + macros |

### Long-Term Customer
| Friction | Recommendation |
|----------|----------------|
| No loyalty path | LTS option · feedback voting · roadmap honesty |
| Churn after silence | Success check-ins (opt-in) · CSAT |

---

## 3. Success metrics (ops design)

| Metric | Intent |
|--------|--------|
| Time-to-activate | Purchase → Activation Success |
| Wizard completion % | Onboarding health |
| Ticket deflect % | KB effectiveness |
| CSAT / NPS | Support + product feel |
| Renewal rate | Commercial retention |

---

## 4. Standing rule

Premium is judged by install · learn · operate · support confidence — not trading claims alone.
