# FIRST_RUN_EXPERIENCE.md

**Product:** THE GOLD MIND AI  
**Audience:** New commercial customer (international)  
**Principle:** The first 15 minutes decide renewal, refunds, and reputation.

---

## 1. Why first-run matters more than Phase 8 features

Customers do not buy modules.  
They buy a feeling of: **“I installed it, I understand it, I trust it, I’m ready.”**

Gold Mind’s Core can be excellent and still fail commercially if first-run feels like a developer cockpit.

---

## 2. Ideal first-run narrative (product storyboard)

### Minute 0–2 — Arrival
- Splash / brand moment: THE GOLD MIND AI  
- Subline: *Professional H4 Gold Strategy Engine*  
- Tone: calm, precise, premium — not hype

### Minute 2–5 — Welcome Wizard (required)
Screens:

1. **Welcome** — what this product does in one sentence  
2. **Safety** — trading risk disclosure acknowledgment  
3. **Mode** — Demo recommended / Live requires confirmation  
4. **Instrument** — confirm gold symbol mapping  
5. **Identity of trades** — Magic Number explained; manual trades never touched  
6. **Risk posture** — Conservative / Balanced / Aggressive (profile language)  
7. **Activation** — license enter / validate  
8. **Permissions** — Algo Trading, chart attach, internet if license needs it  
9. **Ready** — checklist green lights

### Minute 5–10 — Guided cockpit
Show only:

- Strategy status (H4 cycle)  
- Risk status  
- Open AI-managed positions (if any)  
- Next action: “Wait for next H4 decision window” or “System armed”

Hide by default:

- Labs, Monte Carlo, API Gateway, Command Center, multi-account federation

### Minute 10–15 — Confidence
- Link: “How Gold Mind works” (2-minute explainer)  
- Link: “What never happens” (no manual interference)  
- Optional: sample report preview from demo history

---

## 3. Welcome Wizard — product requirements

| Requirement | Why |
|-------------|-----|
| Skippable advanced mode for experts | Pros hate forced tours |
| Cannot skip risk disclosure | Legal + trust |
| Demo default | Reduces catastrophic first-hour losses |
| Magic education | Protects brand when customers mix manual trades |
| Plain language | International buyers + non-English-first users |
| Resume later | Interrupted installs are common on VPS |

---

## 4. Anti-patterns to kill before launch

- Opening on Phase certification widgets  
- Showing “Architecture Ready” as if shipped  
- Requiring customers to understand Phase 1–7 history  
- Exposing every enterprise module on day one  
- Using internal sprint names in UI  

---

## 5. Success metrics (product)

| Metric | Target (soft launch) |
|--------|----------------------|
| Install → Activated | ≥ 85% |
| Activated → First 24h without support panic | ≥ 70% |
| Wizard completion | ≥ 80% |
| Refund reason “too confusing” | < 10% of refunds |

---

## 6. Director decision

**Welcome Wizard: YES — non-negotiable for commercial launch.**  
Expert skip is allowed. Beginner skip of safety screens is not.
