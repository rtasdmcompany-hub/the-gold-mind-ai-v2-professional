# Phase 6 — Operations Manual

## Daily

- Confirm EA running; timer active  
- Glance Remote health / Cloud status / License health  
- Confirm no unexpected critical notifications  

## Weekly

- Review Audit / Compliance summary  
- Confirm Backup health & continuity score  
- Review Deployment current vs latest version  

## Incident

| Event | Action |
|-------|--------|
| Cloud offline | Trading continues — verify Offline Mode banners |
| License grace | Trading continues — renew license when convenient |
| Update available | Install only when GM positions = 0 |
| Audit integrity warn | Export forensic report; do not alter Core |

## Forbidden actions

Never use ops tooling to open/close/modify Gold Mind or manual trades.
