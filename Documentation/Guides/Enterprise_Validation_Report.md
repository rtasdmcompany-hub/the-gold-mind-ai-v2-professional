# Enterprise Validation Report Template

Generated at EA startup by `CGmValidationEngine` when validation is enabled.

## Contents

1. Architecture Status  
2. Module Status (PASS/FAIL per Sprint 1–7 contract)  
3. Strategy Validation  
4. Backtest Metrics (WR, PF, MaxDD, Expectancy, …)  
5. Performance Rating  
6. Risk / Consistency Status  
7. Recovery / Stress Status  
8. Error Classification + recommended fixes  
9. Compiler Status  
10. Code Quality (AI-ready notes)  
11. Overall Score + **PASS / FAIL** decision  

File pattern: `GM_ValidationReport_{magic}_{symbol}.txt`
