# Phase 7 — Administrator Guide

## Attach & license

- Run only on licensed Gold Mind AI terminals.  
- Multi-Account analytics exclude unlicensed accounts.

## Safe operations

- Do not treat dashboard widgets as trade controls.  
- Change templates/profiles only when AI-managed trades are flat.  
- Review `GM_PHASE7_*` closure files after first attach for PASS/FAIL.

## Monitoring

Command Center and Multi-Account Center are monitor-only — no remote commands.
